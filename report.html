Test set and answer key

Each query was written by qwen2.5:7b from one Recipe, then checked by hand. The qrels pool the top 5 Recipes of every configuration, strategy and ablation, and an LLM judged each pair. Recall@5 is exact; Recall@10, Recall@20 and MRR may be slightly low because the pool stops at rank 5.
